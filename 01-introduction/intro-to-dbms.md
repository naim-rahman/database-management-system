# Introduction to Database Management System (DBMS)

## What is Data?

Data is a collection of raw facts and figures that can be processed to produce meaningful information.

**Examples:** Student ID, Name, Age, CGPA.

## What is Information?

Information is processed data that is meaningful and useful.

**Example:** "Naim scored 3.85 CGPA."

## What is a Database?

A database is an organized collection of related data that can be easily accessed, managed, and updated.

**Example:** A university student database.

## What is DBMS?

A Database Management System (DBMS) is software that allows users to create, store, retrieve, and manage databases.

**Examples of DBMS:**

* Oracle Database
* MySQL
* PostgreSQL
* Microsoft SQL Server

## Advantages of DBMS

* Reduces data redundancy.
* Improves data security.
* Supports data sharing.
* Provides backup and recovery.
* Maintains data consistency.

## Disadvantages of DBMS

* High cost.
* Complex system.
* Requires trained personnel.

## Applications of DBMS

* Banking Systems
* University Management Systems
* Hospital Management Systems
* E-commerce Systems
* Railway Reservation Systems
